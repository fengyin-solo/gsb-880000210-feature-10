# solo-8800002

一个基于 Vite + Vue 3 的纯前端小众业务示例项目，主题是古籍虫蛀修复批次管理。

## 开发

```bash
npm install
npm run dev
```

`vite.config.js` 已显式配置 `server.open = false`，启动开发服务时不会自动打开浏览器。

## 构建

```bash
npm run build
```

## 修复备注追踪

每条处理备注带有**时间、修复师、关联工序**，按修复对象（批次编码）归拢：

- **修复工作台**（`/workbench`）：左侧切换对象，支持「全部对象」收拢查看；右侧显示备注线程与录入表单。
- **任务清单**（`/tasks`）：备注数量与最新说明与工作台共用同一个单例数据源，点击「进入工作台」定位到同一对象。
- **防重复**：备注为空、基于过期版本保存（修改冲突）、与最后一条备注的内容/修复师/工序完全相同，均不会产生记录。
- **持久化**：有效保存写入 `localStorage`，刷新后重读最后一次有效内容；写入失败时回滚，保留原版本与表单内容。
- **旧备注只读**：批次档案与任务清单中的原始说明作为种子备注（带「旧备注 · 只读」标记），新流程只能追加，不能覆盖。
- 工作台底部提供原型验证开关：模拟别处修改（版本冲突）、模拟下次写入失败、模拟刷新重读。

核心逻辑为不依赖框架的纯函数（`src/utils/noteThread.js`），校验脚本：

```bash
npm test
```
